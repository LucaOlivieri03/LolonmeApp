# Feature: Fase 1 MVP Core — LolonmeApp
Objective: Build Fase 1 MVP Core of LolonmeApp locally (Next.js App Router PWA, light-mode football aesthetic, anthem player 10s-21s, Supabase SQL+RLS schema, pure tournament engines, constant Excel importer for `docs/LOLONMEBOL.xlsx`, and full mobile-first UI + Admin/Pozo).
Branch: `feat/fase-1-mvp` | Delivery strategy: `ask-on-risk` (forecast: ~2400 authored lines across 6 work units) | Test runner: `pnpm test` (Vitest) + `pnpm build` (Next.js).

## Specs
- **S1 (Setup local y PWA futbolera)**: "1. No tengo proyecto creado, comencemos localmente" + "3. tema claro en un prncipio, estética 100% futbolera. Si, la cancion es el himno, el estribillo (lo que deberia sonar por lo general va del segundo 10 al 21)."
  - Next.js (App Router) + TypeScript + Tailwind CSS + PWA `manifest.json` + official logo (`assets/LogoLOLONMEBOL.svg` & `assets/Logo.svg`) in `public/assets/`.
  - Light-mode 100% football aesthetic using colors derived from `LogoLOLONMEBOL.svg`, mobile-first 5-tab Bottom Navigation (`Inicio`, `Partidos`, `Stats`, `Blog`, `Calendario/Más`).
  - Integrated anthem audio player (`public/assets/cancion.mpeg`) defaulting to chorus playback from second 10 to second 21, with option to play full track.
- **S2 (Base de Datos Supabase, Auth y RLS)**: PostgreSQL schema in `supabase/migrations/0001_initial_schema.sql` matching `docs/plan_tecnico_lolonmebol.md` §2 (`players`, `player_aliases`, `player_titles`, `seasons`, `calendar_events`, `announcements`, `matches`, `match_players`, `match_votes`, `cup_editions`, `cup_ties`, `fund_months`, `fund_payments`, `fund_transactions`, `blog_topics`, `blog_comments`, `match_media`, `clubs_cache`), automatic email-based account linking trigger, and strict RLS (`invitado` public read-only, `player`, `authorized`, `admin` exclusive for Pozo). Local fallback repository so the app runs offline with real Excel data before Supabase credentials are configured.
- **S3 (Motores de Cálculo Puros — Reglamento Oficial)**: Exact implementation of `docs/reglas_torneo_lolonmebol.md` with Vitest TDD:
  - Standings (Anual & Histórica): `3/1/0` Liga & tiebreaker, `4/2/0` Cup teammates, `0` Cup captains & Final LOLONMEBOL; exact tiebreakers (`Pts ↓` → `PJ ↑` → `H2H ↓` → `PG% ↓` → `MVPs ↓` → `Nombre ↑`); 1st/2nd place tiebreaker match alert; configurable `counts_for_league` and `counts_for_stats`.
  - Cup Engine: 9 qualifiers (2 previous LOLONMEBOL finalists + Top 7 with quota release), Preliminary Round (2 lowest non-finalists), Quarterfinals (`1° vs GFP`, `2° vs 7°`, `3° vs 6°`, `4° vs 5°`), two-legged aggregate + seed tiebreaker, full manual Admin overrides (replacements, scores, winner), Final LOLONMEBOL pairing (same winner -> Liga runner-up).
  - Stats Engine: Química (%), Wilson Consistency `CT%` ($z=1.28$), optional `3/1/0` effectiveness toggle, H2H (`V - D`), subgroup analysis, filters by season/all-time and modality (`F5`/`F6`/`F7`/`ALL`).
  - Fund (Pozo) Engine: configurable monthly fee formula `sum(paid * month_fee) - sum(expenses) + sum(yields)`.
- **S4 (Importador Constante de Excel)**: "2. recien lo subi" (`docs/LOLONMEBOL.xlsx`). Server-side parser + name/emoji normalizer (`player_aliases`), dry-run diff preview (`new`, `updated`, `conflicts`, `new_players`), and transactional import / local seed generation for real 2025 & 2026 tournament data.
- **S5 (UI Pública Mobile-First — Fase 1)**: Main Page (Anuncios, Próximo evento, Tabs Tabla Anual / Histórica / Copa interactiva), Partidos (season & type filters + Fechas Especiales + match detail), Stats (Perfil personal con `⭐` + Laboratorio Grupal Química/Wilson/H2H/subgrupos), Calendario mensual con etiquetas de color, y vista placeholder informativa de Blog (Fase 2).
- **S6 (Auth, Roles y Panel de Administración / Pozo)**: Auth + role-based UI (`invitado`, `player`, `authorized`, `admin` + dev role switcher when Supabase is unconfigured), Carga/edición de partidos y rendimientos (`admin` + `authorized`), Gestión de Anuncios y Calendario (`admin` + `authorized`), Editor manual completo del cuadro de Copa (`admin`), Gestión de jugadores y títulos/estrellas (`admin`), Pozo y Premios (`admin` exclusivo), e Importador Constante de Excel con vista previa diff (`admin`).
